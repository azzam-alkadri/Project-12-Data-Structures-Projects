# Data Structures in C++

A collection of fundamental data structure implementations developed in C++ as part of the Algorithms & Problem Solving course.

## Projects

### Project 1 – Doubly Linked List
Implementation of a generic Doubly Linked List with common operations.

**Features**
- Insert at beginning
- Insert at end
- Insert after node
- Delete node
- Delete first
- Delete last
- Reverse list
- Clear list
- Find node
- Print list

---

### Project 2 – Queue using Doubly Linked List

Implementation of a Queue (FIFO) built on top of the Doubly Linked List.

**Features**
- Enqueue
- Dequeue
- Front
- Back
- Size
- IsEmpty
- Print Queue

---

### Project 3 – Stack using Doubly Linked List

Implementation of a Stack (LIFO) using the Doubly Linked List.

**Features**
- Push
- Pop
- Top
- Size
- IsEmpty
- Print Stack

---

### Project 4 – Dynamic Array

Custom implementation of a Dynamic Array without using STL.

**Features**
- Resize
- Insert
- Delete
- Update
- Search
- Reverse
- Clear

---

### Project 5 – Queue using Dynamic Array

Queue implementation built using the custom Dynamic Array.

**Features**
- Enqueue
- Dequeue
- Front
- Back
- Size
- IsEmpty

---

### Project 6 – Stack using Dynamic Array

Stack implementation built using the custom Dynamic Array.

**Features**
- Push
- Pop
- Top
- Size
- IsEmpty

---
